# 配信拡張のクリップ再生

1. JTSAでTwitchアカウントにログインし、使用するアカウントを選択します。
2. OBSに新しい「ブラウザ」ソースを追加し、URLを `http://localhost:8026/expansion-clips` にします。幅1920、高さ1080を推奨します。
3. 配信拡張の抽選アイテムで「OBS実行」から「クリップ再生」を開き、対象ユーザーを選びます。「選択アカウント」「チャットユーザー」「トリガーユーザー」、またはTwitchログインIDの直接指定を利用できます。ログインID指定は空欄で無効になります。
4. 「OBS実行テスト」で確認します。ルールの条件を満たしたときも再生されます。

対象チャンネルの人気クリップ最大100件から1件をランダムに選びます。「そのユーザーが作成した他チャンネルのクリップ」ではなく、対象ユーザーの配信を切り抜いたクリップが対象です。

クリップ専用ソースなので、画像用の `/expansion` とは独立して位置やサイズを調整できます。映像側はミュートされ、音声はJTSAからWindowsの既定の音声出力へ再生されます。配信へ載せるには、その出力デバイスをOBSのデスクトップ音声または音声出力キャプチャで取り込んでください。

通常は透明で、再生要求を受けたときだけTwitch UIのない動画を表示します。OBS側の動画が再生可能になった通知に合わせてJTSAの音声を開始します。再生中に次の要求を受けると、新しいクリップへ切り替えます。動画の終了時、またはクリップの長さ＋読み込み猶予5秒で非表示になります。

チャットユーザーとトリガーユーザーは、テストボタンではイベント情報を取得できません。実際のイベントで確認してください。ユーザーやクリップが見つからない場合、実行時はアプリログ、テスト時はダイアログに理由を表示します。

実機確認：OBSでソースを表示してテストし、映像・JTSAからの音声・自動非表示を確認します。

クリップ動画URLの解決にはTwitch Web内部の非公開APIを使用します。Twitch側の仕様変更により再生できなくなる場合があります。

参照：[Get Clips API](https://dev.twitch.tv/docs/api/reference/#get-clips)。
