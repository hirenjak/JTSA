～～～～～ソフトウェア概要～～～～～
　Twitchで配信を行う際に配信タイトルやカテゴリ設定などを簡易的に行えるように機能を詰め込んだツールとなります。
　現在は主に以下のような機能を有しています。
　　・「配信タイトルの履歴からの流用」
　　・「過去利用したカテゴリの流用」
　　・「Twitchの配信概要変更」
　　・「Xへの投稿画面表示およびテンプレートによる配信通知投稿」
　　・「コラボ時のタイトルへのユーザー入力の簡略化」

～～～～～注意書き～～～～～
　以前のバージョンとの互換性がありませんので、今回インストールする方は以下のアンインストールを行ってからインストールを行ってください。
　本ソフトウェアは


～～～～～アンインストール手順～～～～～
　1．Windowsの設定画面よりアンインストールを行う。
　　　参考：アンインストール方法（ソフト）.png
　2．以下のフォルダ配下にある「JTSA.db」というファイルを削除する
　　C:\Users\<ユーザー名>\AppData\Roaming\JTSA\userdata


～～～～～インストール手順～～～～～
　1．インストール用ファイル「JTSA-win-Setup_X.X.X.exe」をダブルクリックで起動して画面に表示される手順通りに進む
　2．アプリが起動する（しない場合はデスクトップにショートカットが作られている）
　　次回以降はデスクトップのショートカットより起動
　3．初回起動時Twitch認証が必要（それ以降は長期間放置しない限り認証なしで起動可能のはず...）
　4．Twitchユーザー名に自分のTiwtchIDを入力（例：hiren_jak）
　5．OAuth認証ボタンを押下するとブラウザが立ち上がり認証画面が表示される（同時にアプリ側に認証コードが表示されます）
　6．ブラウザ側にてログインを求められる場合はログインする
　7．認証コードが求められた場合、アプリ側の認証コードをブラウザに張り付ける（Copyボタンを押すとクリップボードにコピーされます）
　8．認証を許可するとアプリ側のロード画面が無くなるのでこれでインストール完了です


～～～～～基本的な操作～～～～～
配信概要設定画面にてタイトル編集（左側の白いテキストボックス）を行う
カテゴリ画面にて右側のカテゴリ検索のテキストボックスに設定するカテゴリを入力
対象のカテゴリが出て来たらそのカテゴリをダブルクリック
左側に勝ておgリが表示されたらカテゴリ設定ボタンを押すかカテゴリをダブルクリック
上側に設定内容が表示されてるので問題なければ送信ボタンを押すとTwitchに設定されます
（数字の横に更新ボタンがありますが、こちらは現在Twitchに設定されている配信情報をアプリ側に取得設定するものになります）

X告知ボタンを押すと配信タイトルとカテゴリ、配信URLが記載されたXの投稿画面が表示されます
